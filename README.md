- EstructurasControl - If-else y Switch
- Ciclos - For, While y Do-While
- Metodos - Definicion y uso de metodos

### Semana 2 - POO
- Persona - Clases y objetos
- Calculadora - Metodos en clases
- CuentaBancaria - Encapsulamiento, getters y setters

### Semana 3 - Herencia

- Gato - Herencia y sobreescritura de metodos
